AI-assist model

    

      An optional local model gives a second opinion on pieces diagnostics has already flagged as
      uncertain, in each Act's review screen -- it never parses anything itself, and its answer is
      never applied automatically. Everything runs on this machine via Ollama,
      an open-source model server; nothing is sent anywhere else.
    

    

    

      
      
      
    

    

      
      

    

  







  

    
AI scan — 

    

      The same local model reads every unit of this document, not just the pieces diagnostics has
      already flagged, and says whether each one's type/number/heading/text classification looks
      right. This can take a long time on a real Act -- it runs in the background and picks up
      where it left off if stopped or restarted. Nothing it finds is applied automatically: results
      show up as findings in this Act's review screen, hidden the same way every other finding is
      until a reviewer has recorded their own independent judgement first.
